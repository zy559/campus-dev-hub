# 首页品牌重塑 — 设计规格说明

> 2026-06-11 | 版本 1.0

## 目标

重新设计首页视觉效果，从紫色赛博风改为温暖极简风（参考 Apple + 微信 + Soul），新增全屏滚动宣传页让新用户立刻理解网站用途。

## 配色方案

| 角色 | 旧值 | 新值 |
|------|------|------|
| 主强调色 | `indigo-600` | `orange-500` |
| 强调悬浮 | `indigo-700` | `orange-600` |
| 浅色强调 | `indigo-50` | `orange-50` |
| 强调文字 | `indigo-600` | `orange-600` |
| 强调悬浮文字 | `indigo-800` | `orange-700` |
| 背景 | `gray-50` | `white` / `#fafaf9` |
| 卡片边框 | `border-gray-200` | `shadow-sm`（无边框） |

全部文件：`indigo` → `orange`（46 处）。

## 首页结构（未登录用户）

5 个 Section，垂直滚动：

1. **Hero**：大号 emoji + 标题「校园技术交流社区」+ 副标题「分享知识 · 展示项目 · 找到队友」+ 双按钮（探索帖子/开始创作）
2. **功能卡片**：三栏卡片 — 发帖讨论 / 分享资源 / 组队找人
3. **价值说明**：1-2 块左文右图的宣传位（当前简约占位，后续完善）
4. **社交证明**：已有 XX 篇帖子、XX 位同学加入
5. **帖子列表**：现有帖子流

## 首页结构（已登录用户）

直接显示帖子列表（当前行为，Hero 缩小为顶栏标语）。

## 其他页面

保持功能不变，只替换配色。
